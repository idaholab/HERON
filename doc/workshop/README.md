# HERON Workshop Presentations

Welcome to the HERON workshop presentations! Below is a summary of all the presentations, associated input files, and suggested order of viewing:


## HERON Workshop

* **HERON Introduction & Simple Example** - `1_SimpleCase.pptx`
  - This presentation introduces HERON's computational model and describes a simple three unit system for users to simulate.
  - Associated input files for this simple example can be found in: `HERON/tests/workshop/simple`
* **Nuclear Power Plant & Wind Example** - `WindCase.pptx`
  - This presentation presents a more complex example introducing a wind-farm in combination with a nuclear power plant.
  - Associated input files for this simple example can be found in: `HERON/tests/workshop/wind`
* **Full Integrated Energy System Example** - `HERON_IES_WORKSHOP.pptx`
  - This presentation finishes with a full integrated energy system using: nuclear power plant, steam turbine, high temperature steam electrolysis plant, hydrogen storage, wind, electricity market, and hydrogen market.
  - Associated input files for this simple example can be found in: `HERON/tests/workshop/ies`
